record-and-replay web automation

Record a task once.Replay it forever.

Do a task on any website while Mimic watches — a hotel search, a flight lookup, an email. Mimic turns it into a reusable automation with a fill-in-the-blanks form and a REST API, so you (or your code) can run it again with new inputs and get clean results back.

Run it locally → See the REST API

Chrome extension · Node + Playwright backend · React frontend — self-hosted, open on your machine.

what it does

One recording, many ways to run it

●

Record & replay

The extension captures your clicks and inputs with resilient multi-signal selectors, then replays the task on demand.

▢

Fill-in-the-blanks forms

Mimic reads the recording and generates a clean form — change the destination, the dates, the guests, then press go.

{ }

REST API + keys

Every automation is also an endpoint. Generate an API key, POST your inputs, get JSON results — from any script.

◎

Deterministic site adapters

For sites we understand, Mimic skips fragile replay and builds the real results URL directly — same inputs, same results, every run.

✕

Two ways to run

go runs on the server and returns output here. run in my browser replays in your own logged-in tab for sites that need a session.

how it works

Record → build → run → automate

01

Record

Hit record in the extension and do the task once, on the real site, like you always would.

02

Build

Mimic analyzes the recording and synthesizes a form — the fields it found are the inputs you can change.

03

Run

Enter new values, press go, and get a clean list of results back — hotels, flights, whatever the task returns.

04

Automate

Grab an API key and call the same automation from your own code, on a schedule, or from another app.

run it yourself

Up and running in three terminals

Needs Node 18+ and a Chromium-based browser (Chrome, Edge, or Brave).

# 1 · backend — API + Playwright engine
cd backend
npm install
npm run dev        # http://localhost:4545

# 2 · frontend — the mimic web app
cd frontend
npm install
npm run dev        # http://localhost:5174
# 3 · extension — record on any site
cd extension
npm install
npm run build

# then in chrome://extensions
# → Developer mode → Load unpacked
# → pick the  extension/dist  folder

Optional: drop a DeepSeek API key in backend/.env for smarter form synthesis — without it, Mimic falls back to built-in heuristics.

rest api

Call any automation from code

Create a key in account → API access, then run an automation by id:

curl -X POST https://your-host/api/v1/automations/<id>/run \
  -H "Authorization: Bearer mk_live_…" \
  -H "Content-Type: application/json" \
  -d '{"variables": {"destination": "Bangkok", "check_in_date": "2026-09-10"}}'

Returns JSON: run id, status, and the extracted results array. Keys are per-account; no key, no run.
